# 🌟 Aura Screening

> **A streamlined Software as a Service (SaaS) platform built to accelerate candidate evaluation and optimize the hiring pipeline.**

[![Status: Active](https://img.shields.io/badge/Project_Status-Active-brightgreen.svg)]()

## 📖 Overview

**Aura Screening** is a modern SaaS architecture application designed to fundamentally change how companies handle the initial stages of recruitment. 

**The Motive:** The primary goal of this project is to speed up the initial time of candidate evaluation for a particular job. Traditional resume screening can take hours or even days; Aura Screening reduces this to minutes, allowing hiring teams to focus on interviewing the best talent rather than sifting through unqualified applications.

## 🎯 Who is it for?

This project is tailored specifically for:
- **HR Managers** 
- **Recruiters**
- **Talent Acquisition Specialists**

*Ideal for small to mid-range companies (SMEs) looking to speed up their hiring process, save administrative costs, and improve the overall quality of their candidates without needing enterprise-level budgets.*

---

## ✨ Key Features (Proposed)

- **Automated Resume Parsing:** Instantly extract key information from candidate resumes.
- **Smart Scoring & Ranking:** Automatically rank candidates based on their alignment with the specific job description.
- **Multi-Tenant SaaS Architecture:** Secure, isolated data spaces for different companies and recruitment agencies.
- **Intuitive Dashboard:** A clean, easy-to-use interface for HR managers to track applicant pipelines in real-time.
- **Customizable Screening Criteria:** Tailor the evaluation parameters to fit the exact needs of any specific role.

---

## 🏗️ SaaS Architecture

Aura Screening is built on a robust Software as a Service (SaaS) model, ensuring:
- **Multi-tenancy:** A single instance of the software serves multiple tenants (companies) securely.
- **Scalability:** The architecture is designed to handle spikes in application volume easily.
- **High Availability:** Cloud-native deployments ensure the system is always online for recruiters globally.

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- A running instance of your chosen Database.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/aura-screening.git
   cd aura-screening
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Set up environment variables:**
   Create a `.env` file in the root directory and add your necessary API keys and database URIs.
   ```env
   PORT=3000
   DATABASE_URL=your_database_url
   JWT_SECRET=your_secret_key
   ```

4. **Run the application:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```
